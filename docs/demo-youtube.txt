WeatherQuest: AI-verified gaming bounties on GenLayer (live StudioNet demo)

WeatherQuest is a 2D weather-gated RPG deployed as a GenLayer intelligent
contract. Each campaign level uses a real city; five StudioNet validators
independently fetch the same live Open-Meteo weather, derive the risk
multiplier on-chain, and judge the player's submitted action against a
per-level objective through a structured rubric. The contract, not the model,
derives success, and the payout is base(level) x multiplier with no
caller-supplied term. A deterministic pre-filter reverts obvious prompt
injections before any LLM work.
